## 0. 一句话结论

系统已能完整走完 multi-agent 编排 + HITL + 并发调研 + 跨竞品矩阵 + QA 打回重写 + trace,达到可演示线。剩余问题集中在:report factuality 与渲染卫生、curator 指标口径误判、来源质量门槛弱。Qwen 接入(S1)后模型分档已产生真实质量分层、analyst 长重试已 de-risk;endpoint 脱敏与重试 wall-clock 预算已代码级完成。S2 已补 analyst per-dimension insight 指令与 comparison→conclusion backfill,剩真实 Qwen E2E run 复验。

## 0.1 统一质量原则(沿用)

ToB 竞品分析宁可留白也不能伪造。所有 discovery/research/report/QA 链路继续遵循:

1. **质量优先于延迟/成本**:不为省 token/延迟把语义任务降级成脆弱硬规则。
2. **LLM-first,代码做护栏**:语义判断优先交模型;确定性代码负责 schema、去重、grounding、可观测字段。
3. **No fabrication**:竞品与证据必须来自真实工具观测且可溯源;拿不到证据就标记未覆盖或降级,不合成假竞品/假 quote/假 source。
