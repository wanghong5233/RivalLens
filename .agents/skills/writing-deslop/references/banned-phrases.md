# Banned Vocabulary, Phrases, and Openers

Exhaustive list backing `SKILL.md`. Read on demand when scrubbing a draft. Match across 中文 and English; replace with a concrete fact, metric, or delete.

## 禁短语 / 模板句（中文）

- 这不是 X，而是 Y
- 值得注意的是 / 值得一提的是 / 需要指出的是
- 总而言之 / 综上所述 / 总的来说
- 更重要的是 / 更进一步 / 此外 / 另外值得
- 从某种意义上 / 在一定程度上 / 某种程度上
- 不难发现 / 显而易见 / 众所周知
- 赋能 / 打造 / 助力 / 一站式 / 全方位
- 让我们一起 / 接下来我们来看 / 下面将介绍

## 自夸形容词（无证据即删）

- 强大的 / 优雅的 / 高效的 / 稳定的 / 健壮的
- 业界领先 / 行业标杆 / 创新性 / 颠覆性
- 极致 / 完美 / 卓越 / 顶级 / 革命性

## Banned openers (English)

- Certainly, / Indeed, / Notably, / Importantly,
- Moreover, / Furthermore, / Additionally, / In addition,
- It's worth noting that / It is important to note
- In today's competitive landscape / In the modern era
- Overall, / In conclusion, / To sum up,

## Banned words (English, AI-detection flagged)

- delve, tapestry, landscape, testament, vibrant, pivotal
- realm, navigate (figurative), leverage (verb), utilize (→ use)
- seamless, robust, cutting-edge, game-changer, holistic
- foster, empower, unlock, elevate, harness

## 结构性反模式

- 完美三段式 / 对称节奏：每节同长度、同句式 → 按信息密度重排。
- Rule of three 堆叠：凡事都列三点 → 列真实需要的条数。
- Hedging seesaw：先夸再贬再补一句中庸 → 给单一明确判断。
- 长词替换：`实现` 在"做出来"语境改 `做`；`utilize → use`；`in order to → to`。
- Concept-noun stacks：`维护 X 的运维复杂度` → `X 难维护`。
- Throat-clearing：`接下来要讲的是…` → 直接讲。

## 标点 / 格式 tells

- em-dash 链（一句多个破折号）→ 拆句。
- 感叹号、emoji 项目符号、hashtag 堆叠 → 删。
- 省略号滥用表"意犹未尽" → 删。

## 准确性红线

- 编造统计数字 / 杜撰引用 / 虚构案例 → 删或标注来源。
- 无来源的"研究表明 / 数据显示" → 补出处或删。
