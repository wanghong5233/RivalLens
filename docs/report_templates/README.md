# Report Templates

本目录定义 RivalLens 面向用户的报告形态。

当前结论：`landscape` 不是“竞品分层地图 + 逐竞品画像 + 2x2”的直接输出。那些是分析中间件，不能作为一级报告目录暴露给用户。

## 文件

| 文件 | 用途 |
|---|---|
| `commercial_report_cases.md` | 真实商业报告样例与可复用结构 |
| `market_landscape_template.md` | RivalLens `landscape` 目标报告模板 |
| `report_runtime_contract.md` | 运行时 section、证据、QA 的产品契约 |
| `ai_hardware_run_f28340ca00e3.md` | 本次真实 E2E 偏航诊断 |

## 非目标

- 不复制付费报告全文。
- 不把 analyst workbench 结构当成用户报告。
- 不把公司级泛证据算作目标品类证据。
