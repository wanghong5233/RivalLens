# RivalLens 产品功能清单

文档定位：截至 2026-05-30 的实际功能盘点。配套愿景见 `docs/1-product-vision.md`，架构见 `docs/2-architecture-decision.md`，协议见 `docs/3-schema-and-protocol.md`。

实现状态：✅ 已落地 / 🟡 骨架可用 / 🚧 规划中。骨架表示链路打通但仅最小功能或不带定时调度。

---

## 1. 路由分层

| 层 | 入口 | 用途 | 不变式 |
|---|---|---|---|
| 营销层 | `/`, `/pricing`, `/examples`, `/share/:runId` | 价值表达、案例阅读、报告分享 | 无登录、可被搜索引擎抓取 |
| 工作区层 | `/app/*` | 任务执行、结论管理、订阅追踪 | 与营销层视觉一致但导航与能力分离 |

| 路由 | 功能 | 状态 |
|---|---|---|

## 5. Agent 能力清单

| Agent | 职责 | 输入 | 输出 | 状态 |
|---|---|---|---|---|
| Supervisor | 主循环：选择下一个工具调用（DiscoverCompetitors / ConductResearch / Analyze / Write / Finalize） | run state | tool decision + reasoning | ✅ |
| Researcher | 调研：channel 路由（search_web / fetch_url / parse_page / extract_structured） + 证据落库 | competitor + dimension | evidence rows | ✅ |
| Analyst | 分析：把证据聚合为 conclusion（claim / confidence / risk_flags / evidence_links） | evidence | conclusion records | ✅ |
| Writer | 写作：把 conclusion 渲染为 Battlecard Markdown 报告 | conclusions | report.content_markdown | ✅ |
| QA | 质检：fast-path 规则 + slow-path LLM；reject_to 反向触发指定 Agent 重做 | report + conclusions | qa.outcome | ✅ |
| Skill Curator | 异步学习：从 run trace 提炼候选 skill（applies_to + qa_rule / prompt_template / source_routing） | run end signal | skill_candidates | ✅ |

详细行为见 `docs/2.5-agent-architecture.md`。

## 6. 数据模型 & 持久化

| 表 | 用途 | FK 行为 |
|---|---|---|
| `runs` | 任务主表 | 删除 → 级联清理下列所有表 |
| `steps` | Agent 执行步骤 | `run_id ON DELETE CASCADE` |
| `evidence` | 原始证据 | `run_id ON DELETE CASCADE` |
| `conclusions` | 结构化结论 | `run_id ON DELETE CASCADE` + `step_id CASCADE` |
| `conclusion_evidence` | 结论 ↔ 证据多对多 | `ON DELETE CASCADE` |
| `reports` | Markdown 报告 | `run_id ON DELETE CASCADE` |
| `supervisor_decisions` | Supervisor 决策日志 | `run_id ON DELETE CASCADE` |
| `llm_calls` | LLM 调用 token/latency | `step_id ON DELETE CASCADE` |
| `artifacts` | 步骤产物 | `step_id ON DELETE CASCADE` |
| `skill_candidates` | Curator 候选 | 不与 run 强绑 |
| `watchlist` | 竞品追踪 | 独立 |
| `checkpoints*` | LangGraph 状态 | 独立 |

完整 schema 见 `docs/3-schema-and-protocol.md` §2。
